## New

- Picker, a third program: `pick` — SELECT and DESCRIBE inside declared SQL
  Server databases, and nothing else. No default database, no `USE`, no
  system catalog; databases, objects and columns scoped one by one in
  `.picker.json` + `.picker.local.json`; one statement at a time through a
  fail-closed ScriptDom gate that rewrites the parsed tree, so the caller's
  string never reaches the server. An object outside the grant is refused in
  the same words as one that does not exist. A CLI for a script and an MCP
  server for a model (`pick serve`) over the same core, with exit codes that
  are fettle's numbers where the words match. Many servers and many
  databases in one boundary: a statement may join across databases on the
  same server, one server per statement, and an unqualified name is proven
  unique across everything declared before it resolves.
- The disclosure screen, over result sets: a database or scope may declare
  `screen`, with the same four categories, the same tier-one detectors
  (held byte-equal to fettle's by a verifier), and the same `burler`
  sidecar and models — one models installation serves both programs.
- Docs: the site is now two lanes with equal treatment — fettle and pick
  each carry Overview, Workstation, Quick start, Install, In a project,
  Screening, Models and Reference, with a program switcher on every page
  that jumps to the same section on the other side. New diagrams draw the
  picked workstation and the one way onto a database server.
- The devlog: the conversation in which Fettler was commissioned, shaped
  and named — the author's messages verbatim — is now a page of the site,
  linked from Authorship, whose record section condenses it into the
  decisions each message made. The working transcript rides along in
  `docs/fettler-design-transcript.md`, repaired: it had arrived with every
  em dash mangled through a console codepage, a fault family the encoding
  verifier now catches.
- Release and install carry the third program: 18 archives (three programs,
  six RIDs), the release checks — executable bit, version stamp,
  NOTICE/LICENSE — assert all three, and
  `fettler-install.ps1 -Program pick` installs it locally.

## Changed

- fettle now refuses to write `.picker.json` and `.picker.local.json`: both
  names join the governed list (exit 11), on the same terms as
  `.fettler.json` itself, because they are the whole boundary of pick —
  which has no write path of its own and re-reads them before every call.
  If those names exist in a tree fettle can write, edits to them through
  fettle are now refused; a person edits them.
