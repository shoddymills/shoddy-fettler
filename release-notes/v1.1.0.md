## New

- `read` now opens the file types a developer actually has, not only source:
  notebooks as cells with their outputs and errors, spreadsheets as rows with
  their formulas, Word documents as paragraphs under their headings, PDFs as
  text per page, images as facts, and entries inside archives without
  unpacking them.
- `fettler-install.ps1` / `fettler-install.sh` - build a self-contained
  `fettle` (or `burler`) for this machine and install it over the one already
  on `PATH`, without stopping a running copy; `-Stop` ends the servers still
  on the old build, after the new file is in place and proven.
- Docs: a full reference page - every verb, every refusal, every exit code,
  the threat model - and a page for the screening models.

## Changed

- Every repository script is prefixed `fettler-`, and the committing task is
  `checkin` rather than `commit`. An assistant's permission layer reads these
  names, and a task named with a bare git word can be refused as the raw
  command it resembles. Maintainer-facing only: the shipped binaries are
  unchanged by the rename.
