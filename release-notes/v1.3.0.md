## Changed

- Every message fettle, pick and burler print is rewritten in plain
  language: refusals, `doctor` and `setup` reports, `help`, the MCP tool
  descriptions and the MCP instructions. Each message now says what
  happened in its first sentence and what to do in its second. Exit codes,
  JSON `outcome` words and the doctor check numbers (2.6, 2.8, B.17 and the
  rest) are unchanged, so scripts that branch on them do not need updating.
  Scripts or tests that match on the old wording of a message do.
- The documentation site and the root Markdown are rewritten in the same
  plain style: short sentences, short paragraphs, no em dashes, terms
  defined at first use. Every page quotes the new program output.
- The instruction block `fettle setup` writes into `CLAUDE.md` and
  `copilot-instructions.md` is rewritten to match. Re-run
  `fettle setup <client> --local` to update an existing block in place.

## New

- `scripts/fettler-survey-readability.js` measures every docs page and
  root Markdown file against the house readability standard. It is the
  `survey-readability` task.
- `fettler-verify-docs.js` now fails on any character outside ASCII in a
  docs page, a docs SVG or a root Markdown file. Write an entity instead.
